OGS app · spec proposal · profiles & friends · Oct 2026

You have an OGS profile. Games already know your name.

Onboarding makes your profile once. Every game you join gets a signed token with your name and avatar, so no game asks "Who's playing here?" again. Families become friends; the TV session is whoever joined this cast.

1 · Onboarding

One step makes your profile; kids are added by a grown-up

Replaces "Who's in your family?" in the same slot (after notifications). Only the name is typed. The @id is pre-filled from the name. Kids never type: a grown-up adds them, and a kid's iPad is signed in by scanning the grown-up's phone.

3 · Games know who you are

A signed, per-game profile token, delivered two ways

The app asks OGS for a token for this game only. In the phone's WebView it arrives in a new profile bridge store. On the TV, ogs:start.token (empty today) carries a session token naming every player. Game servers verify with OGS's public key.

5 · Decide

Six choices, each with a recommendation

Q1 · Profile idWhat is your OGS Profile Id?
AA unique @id, pre-filled from your name, editableRec
BNo @id: friends add you only by QR or link
CA random code (e.g. KITE-4821), not editable
A matches "you create your OGS Profile Id" and makes "find by @id" possible; pre-fill keeps it one tap.
Q2 · KidsHow do kids get a profile?
AManaged kid profiles under a grown-up: no @id, no own friends, iPad paired by scanRec
BKids get full profiles like grown-ups
CNo kid profiles: kids are names typed per game
A keeps kids out of social features and still skips the name form on Juneau's iPad.
Q3 · Joining a TV sessionWho can join your cast?
AYour kids automatically, friends by a Join card, anyone else by the code on the TVRec
BOnly by scanning the code on the TV
CAnyone on the same Wi-Fi
A uses the friends list for something, and the TV code still covers guests.
Q4 · Id a game seesWhich id does a game get?
AA per-game id (stable in one game, unlinkable across games)Rec
BYour real OGS profile id everywhere
A stops games from joining their data on you; each game still recognises you every time.
Q5 · Age to gamesDoes a game learn kid or grown-up?
AYes, one flag: kid: true | falseRec
BThe full band: grown-up / kid / little
CNo: name and avatar only
Games can pick easier roles or hide chat for kids without learning an age.
Q6 · Losing a phoneHow does a profile survive a new phone?
ASign in with Apple or Google, offered after onboarding ("Back up your profile")Rec
BSign in with Apple or Google required to make a profile
CDevice-only for now; a lost phone loses the profile
A keeps onboarding to one typed name; friends and kids are worth backing up once you have them.
