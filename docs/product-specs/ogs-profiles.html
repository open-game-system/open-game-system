3 · Games know who you are

A signed profile token, scoped to one game

Phone WebView: new profile bridge store. TV page: ogs:start.token (empty today) names the players. Game servers verify with OGS's public key.

Game side: one hook

// undefined → asking the app (≤300 ms)

A game sees
  • Your OGS profile id
  • Your @id
  • Display name
  • Avatar (sticker image URL)
  • On the TV: who's playing this game in this session
A game never sees
  • Your friends list
  • Your other games
  • Device ids or push tokens
  • The app's own OGS token
  • Your age
How we test it

Sign-in is e2e-tested with no real accounts

vercel-labs/emulate runs local Apple and Google OIDC (RS256 ID tokens) and Resend for email. The API points its issuers and mail sender at it in tests.

# one process, all three providers
npx emulate

# test env for services/api
APPLE_ISSUER=http://localhost:…/apple
GOOGLE_ISSUER=http://localhost:…/google
RESEND_BASE_URL=http://localhost:…/resend
E2E path

Make profile → Back up with Apple (or Google, or email code read from the emulated inbox) → API verifies the ID token against the emulator's JWKS → wipe the app → sign in → same @id and friends.
